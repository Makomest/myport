Key advantages

Real-time multiplayer

One shared race runs for every connected player — live drivers leaderboard, live chat and a synchronized round loop create social tension on every bet.

Strategy-proof math

EV equals the RTP for any cash-out target and any car chosen. Players can't out-math the house; operators get a stable, certifiable margin.

Provably fair

Every crash point is committed (hashed) before betting and revealed after, with a built-in client-side verifier — full transparency, zero trust required.

Mobile-first

Fully responsive from 320px phones to desktop: collapsible panels, one-tap betting, sound controls and a fast PWA shell.

Gameplay

  • Pick a car — three cars (Red, Blue, Yellow) line up each round; choose one to back.
  • Place up to two bets per round, each with its own stake and optional auto cash-out target.
  • Auto-bet — let it ride for N rounds automatically.
  • Watch the multiplier climb as the cars race — and cash out before your car breaks down.
  • If your car crashes before you cash out, the bet is lost. The longer you wait, the bigger the payout — and the bigger the risk.

Math & fairness

  • Classic crash survival function: P(crash ≥ m) = RTP / m, so cashing at any target T returns EV = T·(RTP/T) = RTP.
  • All three cars draw independently from the same distribution — car choice never changes the odds.
  • Server-authoritative: crash points are decided server-side from a committed seed; the client only ever renders events.
  • Commit → reveal: SHA-256 of the server seed is published before betting; the seed is revealed at settle so anyone can recompute and verify (HMAC-SHA256, byte-identical client verifier included).
  • Max-win cap and a 97% RTP are enforced in the engine and parity-tested against a reference simulation.

Technology & integration (operator-ready)

  • Front end: dependency-free HTML5 / PWA, WebSocket real-time, responsive down to 320px.
  • Back end: Node + TypeScript, one authoritative round loop, allow-listed & rate-limited inbound protocol.
  • Wallet: idempotent, append-only ledger (debit once / pay once); Postgres adapter with row-locked transactions and exact NUMERIC money; or a seamless operator-wallet API.
  • Auth: operator-signed JWT; production refuses to boot unauthenticated.
  • Responsible gaming: bet / loss / session limits, self-exclusion, reality-check nudges.
  • Ops: Prometheus metrics & live RTP, health / readiness probes, optional Redis for stateless rounds across a fleet, Docker-ready.
